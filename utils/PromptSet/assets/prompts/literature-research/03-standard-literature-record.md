## 标准文献记录模板

角色：资深隐私计算 / 密码学方向研究者，严格基于论文原文进行结构化拆解，**禁止自行推演、编造信息、过度引申；原文无信息则标注【原文未说明】，不得凭空猜测**。

任务：精读目标论文，按照下面 17 个固定模块输出结构化 Markdown 笔记。

**论文完整标题**：xxxxxx

1. **文献身份**

   记录作者、发表年份、出版物会议 / 期刊、DOI、arXiv / IACR ePrint 编号、官方链接、文献类型（会议长文 / 短文 / 预印本）、版本号、信息核验来源。

2. **一句话定位**

   一句话概括论文研究对象、核心方法、目标。仅使用论文明确给出信息，杜绝额外推断。

3. **研究问题**

   梳理研究背景、待解决具体问题、现有工作存在的缺口。

4. **系统模型与威胁假设**

   参与方、数据持有关系、信任模型、攻击者能力、威胁模型；区分公开信息、秘密信息。

5. **方法概述**

   按照信息流 / 计算流程重构整体方案，清晰说明输入、输出、核心模块、模块交互逻辑。

6. **关键技术机制**

   逐条整理核心算法、密码学原语、网络 / 算子设计、模型结构、关键优化与设计选择。

7. **理论结果**

   记录正式定义、引理、定理、安全性质、正确性结论、复杂度边界，以及结论成立的前提条件。

8. **实验设计**

   数据集、数据划分、对比基线、超参数、硬件环境、网络配置、评价指标、重复实验设置、消融实验方案。

9. **实验结果**

   原文报告的核心实验结论，完整保留对比条件、指标单位、实验环境。

10. **作者明确贡献**

    仅提取作者在摘要、引言、结论中**主动声明**的贡献，不要自行总结创新点。

11. **局限性与适用边界**

    分为两类：①作者正文明确提出的局限；②从模型假设、实验范围可直接观察到的边界约束。

12. **与当前项目的关联**

    分析该文献能够支撑 / 补充 / 限制我方项目哪些问题；区分可以直接复用的模块、无法直接迁移的内容。

13. **与其他文献的关系**

    该工作与已有文献的关系：改进、扩展、对比、复用原语、结论冲突、互为补充等。

14. **证据索引**

    对所有核心结论标注定位信息：章节、页码、公式编号、图表编号、定理编号，方便回溯核验。

15. **待读问题**

    记录论文没有解答、尚未核验、表述模糊、需要进一步查证的疑问。

16. **可信度与适用范围**

    元数据核验程度、当前阅读深度；明确所有理论与实验结论成立的约束条件，记录笔记可靠程度。

17. **更新记录**

    时序记录版本变更：理解修正、项目关联调整、新增证据、勘误信息。

**强制输出规则**

1. 全部使用 Markdown 分级条目；每个模块清晰标标题；
2. 任何不存在于原文的信息，统一标注【原文未提及】；
3. 禁止主观评价、不要输出 “本文很好 / 存在缺陷” 这类主观评述，只客观提取事实；
4. 所有技术论断尽量保留原文术语，不随意替换领域专有名词；
5. 证据索引尽可能完整，没有页码时标注章节位置。
