## 图片反推提示词

### 1、通用图片反推

请详细分析并反推我提供的这张图片，尽可能还原其完整的视觉生成逻辑，并整理成可直接用于 Midjourney、Stable Diffusion、Flux、即梦、可灵、豆包等 AI 绘图工具的高质量提示词。分析时不要只描述画面中“有什么”，还需要进一步判断这些元素“是什么风格、如何呈现、为什么形成当前视觉效果”，并从主体、环境、风格、构图、镜头、光线、色彩、材质、质感、氛围、清晰度和细节表现等角度进行系统拆解。

1. **主体与画面内容分析：** 准确描述图片中的核心主体、次要主体、前景、中景、背景、环境元素、装饰元素及主体之间的位置关系；说明主体的外观、形态、姿态、动作、朝向、比例、数量、表情、服饰、道具以及具有辨识度的局部细节。如果存在人物、动物、建筑、产品、植物、文字或抽象图形，需要分别说明其视觉特征及在画面中的重要程度。
2. **视觉风格与艺术方向：** 判断图片整体属于摄影、写实、电影感、商业广告、概念艺术、数字绘画、插画、动漫、复古、极简、未来主义、赛博朋克、超现实、3D 渲染、黏土、潮玩或其他视觉类型，并进一步描述其艺术语言、视觉年代感、设计倾向和表现技法。避免只使用笼统的“高级感”“氛围感”等词汇，应拆解形成这种效果的具体视觉因素。
3. **色彩与配色分析：** 提取主色、辅助色、点缀色和背景色，分析画面的冷暖倾向、明度、饱和度、色彩对比、邻近色或互补色关系，并说明是否存在低饱和、莫兰迪、高饱和、黑金、奶油色、复古褪色、电影青橙、霓虹等具体配色特征。同时判断阴影、高光和环境色对整体色调产生的影响。
4. **光影与照明方式：** 判断主要光源的位置、方向、软硬程度、亮度和色温，并分析自然光、窗光、顶光、侧光、逆光、轮廓光、柔光箱、聚光灯、环境光、霓虹光、体积光等可能使用的照明方式。描述高光区域、阴影范围、明暗对比、反射、折射、光晕、光斑以及整体曝光特征。
5. **构图与镜头语言：** 分析图片采用居中构图、对称构图、三分法、黄金分割、对角线、框架式、留白、满版、层叠或其他构图方式，并判断主体在画面中的占比及视觉重心。进一步分析景别、视角、透视方式、镜头高度、俯拍、仰拍、平视、广角透视、长焦压缩、近距离特写以及可能的焦段特征，并说明景深、虚化和焦点位置。
6. **材质与表面质感：** 描述画面中主要对象的具体材质，例如金属、玻璃、塑料、树脂、陶瓷、木材、纸张、织物、皮革、石材、液体、磨砂、镜面、半透明、亚克力等，并分析其粗糙度、光泽度、透明度、反射强度、边缘质感和微观纹理表现。如果是绘画作品，则分析纸张纹理、颜料堆叠、笔刷痕迹、颗粒或数字绘画肌理。
7. **清晰度与细节表现：** 判断图片属于高清商业摄影、电影画面、8K 级细节表现、柔焦、胶片颗粒、高动态范围、锐利细节或其他画质倾向，并说明主体边缘、皮肤纹理、毛发、织物、金属反光、背景细节等区域的精细程度。不要简单堆叠“8K、超高清”等词汇，应结合实际图片选择适合的画质关键词。
8. **氛围与情绪表达：** 分析画面呈现出的宁静、温暖、清冷、梦幻、神秘、浪漫、未来、复古、庄重、轻松、治愈、孤寂、紧张等情绪，并说明形成该氛围的具体视觉依据，包括色温、光比、天气、环境、主体状态及构图节奏。
9. **关键词提取与 Prompt 输出：** 最后根据以上分析提取“主体、场景、风格、色彩、光影、镜头、构图、材质、质感、氛围、清晰度、细节”关键词，并将其重新组织成自然、准确、适合 AI 识别的提示词。提示词应以重要信息优先排序，避免同义词反复堆叠，不添加图片中缺乏依据的内容。
10. **中英双语输出：** 请分别生成中文版和英文版完整 Prompt。中文版应便于中文 AI 绘图平台直接使用；英文版应使用自然的视觉设计与摄影专业表达，不要采用机械逐字翻译。英文 Prompt 应包含 subject、environment、composition、camera angle、lighting、color palette、materials、texture、atmosphere、visual style、image quality 等核心信息。

最终按照“画面分析 → 风格拆解 → 色彩与光影 → 构图与镜头 → 材质与质感 → 关键词 → 中文完整 Prompt → English Full Prompt”的顺序输出。

4. **配色方案：** 提取字体主体色、描边色、阴影色、背景色和高光色，分析是否使用纯色、双色、渐变、金属渐变、彩虹渐变、霓虹渐变或半透明叠色，并说明冷暖关系、明暗对比、饱和度和视觉重点。
5. **文字特效分析：** 判断是否使用描边、外发光、内发光、投影、长阴影、辉光、渐变、浮雕、颗粒、故障、扫描线、切片、错位、模糊、拖影、反射、折射、镭射、液态、火焰、冰晶或其他特效，并说明效果的方向、强度和层次关系。
6. **Logo 构图与比例：** 如果图片属于 Logo 或品牌字标，请分析图形与文字的组合方式、横版或竖版结构、图文比例、留白、字距、行距、对齐方式和视觉中心，同时分析符号是否由字母变形、几何图形、负空间、徽章结构或抽象图形构成。
7. **光影与展示方式：** 分析文字是在平面画布、实体标牌、墙面、产品包装、屏幕、发光灯箱还是 3D 场景中展示，并判断正面光、侧光、顶部光、背光、轮廓光和环境反射对文字立体感产生的影响。
8. **最终提示词生成：** 提取“字体类别、字形结构、笔画、字重、衬线属性、边角、材质、配色、光泽、立体效果、描边、渐变、发光、背景、排版、整体风格”等关键词，生成一版详细中文 Prompt 和一版适用于英文 AI 绘图模型的 English Prompt。提示词需要明确说明需要生成的具体文字内容，并强调保持文字主体清晰、结构统一、视觉中心稳定。

最终按照“字体风格 → 字形结构 → 材质与特效 → 配色 → Logo 构图 → 光影 → 核心关键词 → 中文 Prompt → English Prompt”的顺序输出。
