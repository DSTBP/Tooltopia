## Latex 格式审查

请完整分析整个 LaTeX 项目文件，包括 `main.tex` 及其引用的所有 `.tex` 内容，全面检查其中可能影响 IEEE conference/journal paper 排版规范的人工布局、间距控制、浮动体设置、格式修改以及自定义宏定义。

请以最新 IEEE 官方 LaTeX 模板和排版规范作为判断依据，不依据个人审美或常规排版习惯进行评价。重点判断当前写法是否符合 IEEE 推荐方式，以及是否存在通过人工调整破坏模板一致性的情况。

不要直接修改原始 `.tex` 文件，只输出独立的 Markdown 格式审查报告。报告需要覆盖整个项目中的相关问题，包括正文、figure、table、公式环境、列表环境、自定义命令、自定义宏以及版式参数设置。

### 审查范围

请重点检查以下类型的问题：

**1. 人工间距和位置调整**

检查所有用于人为控制布局、空白或位置的命令，包括但不限于：

```
\vspace
\vspace*
\hspace
\hspace*
\makebox
\raisebox
\kern
\phantom
\rule
```

同时检查所有自定义宏（例如 `\newcommand`、`\def` 等）是否封装了上述命令或其他形式的人工排版调整。

重点识别：

- 通过手动增加或减少空白调整页面布局；
- 通过强制移动元素位置实现对齐；
- 通过隐藏内容、占位符或不可见元素控制版式；
- 依赖人工微调而非 IEEE 模板默认机制实现的排版效果。

**2. 页面布局和版式参数**

检查是否存在以下不符合 IEEE 模板规范的设置：

- 自定义页边距；
- 修改页面尺寸；
- 修改标题、章节、caption、浮动体之间的默认间距；
- 修改行距或整体版式参数；
- 通过手动设置改变 IEEE 模板默认排版逻辑。

**3. 字号和字体控制**

检查是否存在人工指定字号或字体大小的方式。

允许的 IEEE 常见方式包括：

```
\small
```

例如表格内容过宽时，可以使用 `\small` 压缩表格内容。

禁止使用：

```
\fontsize{}
\scriptsize
\tiny
```

以及其他人为控制正文或局部区域字号的方法。

**4. 列表环境**

检查所有列表环境（如 `itemize`、`enumerate` 等），禁止通过参数手动调整布局。

重点检查是否存在类似：

```
[label=\textbullet,leftmargin=1.8em]
```

以及任何通过 `enumitem` 修改以下参数的方式：

```
leftmargin
itemsep
parsep
topsep
```

列表应尽量遵循 IEEE 模板默认样式，不通过人工参数控制间距和缩进。

**5. Figure 和 Table 环境**

检查所有图片和表格环境是否符合 IEEE 推荐结构。

重点检查：

- 是否使用标准单栏或双栏浮动方式；
- 是否存在 `minipage` 实现复杂布局；
- 是否存在嵌套子图环境；
- 是否通过额外空白命令调整图表位置；
- 是否通过复杂布局手段强行实现排列效果。

禁止出现类似通过 `minipage` 包裹多个图像或子图的复杂布局方式。

推荐参考格式：

```
\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{Figure/xxxx.pdf}
\caption{xxxx.}
\label{fig:xxxx}
\end{figure}
```

表格推荐保持 IEEE 紧凑结构，例如：

```
\begin{table}[t]
\centering
\small
\setlength{\tabcolsep}{1.25pt}
\begin{tabular}{@{}cccccc@{}}
...
\end{tabular}
\caption{xxxx.}
\label{tab:xxxx}
\end{table}
```

其中允许使用 IEEE 常见压缩方式，但不能通过大量人工空白调整实现布局。

### 审查原则

所有修改建议必须遵循以下原则：

- 不直接修改原 `.tex` 文件；
- 只提供问题定位和最小修改建议；
- 不进行代码重构；
- 不改变公式内容、数学符号、变量名称和公式推导；
- 不调整公式内部换行方式；
- 不修改图表数据、caption 含义或正文表达；
- 不因为视觉美观主动调整排版；
- 只判断是否符合 IEEE 官方格式规范。

修改建议应优先采用 IEEE 模板默认机制，而不是新增人工控制代码。

### 输出格式要求

最终输出一个 Markdown 格式审查报告，不包含修改后的 `.tex` 文件。报告需要覆盖整个文件中的所有相关问题，不允许只检查部分章节。

每个发现的问题必须包含以下信息：

- 问题位置：说明问题出现在哪个文件、章节、环境或相关代码区域。

- 当前写法：展示或描述当前存在问题的 LaTeX 写法。

- 存在的问题：说明该写法如何影响 IEEE 排版规范，以及为什么属于不推荐的人工调整方式。

- IEEE 规范依据：说明该问题违反或偏离 IEEE 官方模板推荐习惯的原因。

- 最小修改建议：给出保持论文内容不变情况下的最小调整方案，并提供符合 IEEE 规范的 LaTeX 写法示例。

最终报告应重点关注排版规范、浮动体布局、间距控制、自定义宏风险以及 IEEE 兼容性，避免泛泛而谈，确保覆盖整个 LaTeX 项目。该审查任务的目标是发现所有可能导致 IEEE 模板不兼容的问题，而不是优化论文视觉效果。
